Privacy policy

form mcp · aggiornata il 26 ottobre 2026

A chi si applica

form mcp è uno strumento personale. Lo usa solo il proprietario, sul proprio computer e con il proprio account Google. Nessun altro utente può accedervi.

Quali dati usa

Con l'autorizzazione del proprietario, l'app accede a questi servizi del suo account Google:

  • Google Moduli: creare e modificare moduli e leggere le risposte;
  • Google Drive: elencare, creare ed eliminare i file dei moduli;
  • Google Documenti e Fogli: leggere e scrivere i file collegati ai moduli.

Dove restano i dati

L'app gira solo sul computer del proprietario. Il token di accesso a Google è salvato in un file locale su quel computer. L'app non ha server propri e non invia i dati a terzi. Li passa soltanto all'assistente Claude del proprietario, quando è lui a chiedere un'operazione.

Condivisione e vendita

I dati non vengono venduti, condivisi o usati per pubblicità o profilazione. L'uso dei dati ricevuti dalle API Google rispetta le norme sui dati utente dei servizi API di Google, compresi i requisiti di uso limitato.

Revoca dell'accesso

L'accesso si può revocare in qualsiasi momento dalla pagina Accesso di terze parti dell'account Google. Cancellando il file del token sul computer, l'app perde ogni accesso.

Contatti

Per domande: profilo GitHub del proprietario.
